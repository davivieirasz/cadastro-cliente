# 📋 Sistema de Cadastro de Clientes - Delphi

## 📖 Sobre o Projeto

Este projeto consiste em um **Sistema de Cadastro de Clientes**,
desenvolvido em **Delphi Desktop (Windows)** como parte de estudos
práticos da linguagem e do ambiente de desenvolvimento.

O objetivo inicial foi compreender melhor o funcionamento do Delphi,
explorando componentes da Component Palette, eventos, estrutura de
formulários e conexão com banco de dados.

Apesar de ter sido iniciado com finalidade educacional, o sistema já foi
pensado para **uso real**, atendendo à necessidade de uma contadora
autônoma que precisava organizar e controlar seus clientes de forma
simples e centralizada.

------------------------------------------------------------------------

## 🎯 Objetivo do Sistema

O sistema tem como finalidade:

-   Armazenar informações de clientes
-   Facilitar a consulta e manutenção dos dados cadastrados
-   Auxiliar no controle da quantidade de clientes ativos
-   Centralizar as informações em um único ambiente

------------------------------------------------------------------------

## 🧱 Tecnologias Utilizadas

-   Delphi (Windows Desktop)
-   Programação orientada a eventos
-   Banco de dados relacional
-   Conexão com banco via componentes nativos do Delphi
-   Git para controle de versão
-   GitHub para hospedagem do repositório

------------------------------------------------------------------------

## ⚙️ Funcionalidades Atuais

### 🔐 Tela de Login

-   Acesso restrito ao sistema
-   Validação de usuário cadastrado
-   Redirecionamento para o menu principal após autenticação

### 🏠 Menu Principal

Após o login, o usuário possui acesso às funcionalidades do sistema:

-   Cadastro de novos clientes
-   Visualização dos clientes cadastrados
-   Edição de informações existentes
-   Controle básico dos registros salvos
